---
title: "Appendix A. Key Terms"
---

| Term | Meaning |
| --- | --- |
| RVX ID | RAVIXO account identifier |
| dUSDC / dUSDT | Simulated units used in Demo modes |
| RXP | Non-transferable product experience points |
| Earned RVX Allocation | Verified pre-TGE reward entitlement in the allocation ledger |
| RVX | Planned native network and ecosystem fee asset |
| QAU | Qualified Active User meeting the applicable quality and activity criteria |
| Season | A reward period with published budget, dates and rules |
| Snapshot | Cutoff and approved dataset used for token distribution |
| TGE | Token-generation and distribution event |
| Mainnet | Production RAVIXO blockchain |
| RVX Miner | Community mining-game prototype with campaign and equipment progression |
| Mine RVX | Non-transferable game points used for RVX Miner equipment; not RVX tokens or allocations |
| Parts | Internal resources required for selected game unlocks and upgrades |
| Mastery XP | Character- and tool-specific progression earned using equipped items |
| Arcade prestige | Earned game titles and cosmetics, separate from platform fee VIP tiers |
| Journey Race | Weekly, server-confirmed Campaign-stage leaderboard awarding internal game resources |
| Simulated USD | Demo gift values without a funded cash balance or withdrawal right |
