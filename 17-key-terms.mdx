---
title: "Appendix A. Key Terms"
---

| Term | Meaning |
| --- | --- |
| RVX ID | RAVIXO account identifier |
| dUSDC / dUSDT | Simulated units used in Demo modes |
| RXP | Non-transferable product experience points |
| Earned RVX Allocation | Verified pre-TGE reward entitlement in the allocation ledger |
| RVX | Planned native network and ecosystem fee asset |
| QAU | Qualified Active User meeting the applicable quality and activity criteria |
| Season | A reward period with published budget, dates and rules |
| Snapshot | Cutoff and approved dataset used for token distribution |
| TGE | Token-generation and distribution event |
| Mainnet | Production RAVIXO blockchain |
