---
title: "5. Data Hub and AI Signals"
---

Data Hub is the information layer of the RAVIXO ecosystem. Its planned scope is based on the data categories already defined for the product.

| Data category | Intended information |
| --- | --- |
| On-chain | Exchange inflows and outflows, large-wallet activity, token supply and supported valuation measures such as MVRV, SOPR, NUPL and realized price |
| DEX | Trending tokens, pool liquidity, volume, market depth, token history and observable wallet activity |
| Derivatives | Open interest, funding, liquidations, long/short measures and liquidity context |
| Social | Discussion activity, sentiment, notable keywords and changes in attention |
| Technical | MA50/MA200, RSI, MACD, volume, Bollinger Bands, ATR and relevant price behavior |

Coverage depends on the supported asset, network and source. A metric that is unavailable for a token is shown as unavailable rather than treated as a valid zero. The interface should identify the source and last update time for supported data.

AI Signals are planned to organize this information into understandable context: notable tokens, trends, watchlists, filters and alerts. Each displayed signal should explain the main contributing factors, the relevant data window and the update time.

Signals are information tools for user research and strategy testing. The model implementation, supported integrations, coverage and evaluation details are published when confirmed. A displayed signal is contextual research information rather than a guaranteed trading outcome.
