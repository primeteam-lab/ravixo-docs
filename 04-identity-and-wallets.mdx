## 4.1. RVX ID

RVX ID is a RAVIXO account identifier. It is not the RVX token and is not a wallet private key. It connects account activity, quest verification, referral attribution and eligible reward records.

Only one qualifying account per person is permitted for reward programs. Account security and wallet security are separate: email verification or account 2FA does not recover an external wallet's private key.

## 4.2. Demo Wallet

The Demo Wallet contains simulated assets such as dUSDC and dUSDT. These units cannot be withdrawn, sold or converted into real stablecoins.

Separate ledgers keep different activities independent:

- Practice Balance is for learning and does not determine contest prizes.

- Demo Trading Contest Balance provides 10,000 dUSDC for each weekly contest when that contest is opened.

- Demo Experience Balance supports Demo Swap.

Demo Swap activity does not change Demo Trading PnL, drawdown or TraderScore. A simulated balance is never represented as money held in a user-controlled on-chain wallet.

## 4.3. Live Wallet

In the DEX experience, Live Wallet means the interface to a user's connected self-custodial wallet. Users control their private keys and sign supported on-chain transactions themselves. RAVIXO does not provide a custodial exchange balance for the current DEX model.

Asset movements occur through supported blockchain transactions and the pools, routers or contracts approved by the user. The interface displays the relevant network, assets, balances, transaction status and estimated costs. Demo mode does not create these transactions.

Live Wallet can display RVX only when RVX has been issued and the relevant network and wallet support are available. Test-phase allocations remain in the reward ledger until distribution; they are not spendable wallet tokens.

The custody and execution models of any future order-book or derivatives product will be described separately before that product opens.
